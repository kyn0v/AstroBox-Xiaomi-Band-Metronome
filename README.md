# 手环节拍器

小米手环 9 Pro 上的前台节拍器应用，使用 Vela JS 开发。

[英文说明](README.en.md)

## 功能

- 速度范围 50–250 BPM，支持百／十／个三列数字滚轮调速和击拍测速。
- 支持 2/4、3/4、4/4、6/8，每拍可设为长振动、短振动或无振动。
- 振动和闪烁可独立开关，正常界面的拍点显示当前小节位置。
- **前台暗屏练习**：黑色页面继续振动，点击恢复，不重新起拍。
- 四种主题配色，设置保存在本地。
- 界面支持简体中文和英文，跟随系统语言。

## 操作

点击首页中央按钮开始或停止。

| 首页手势 | 功能 |
| --- | --- |
| 左滑 | 调整速度、击拍测速 |
| 上滑 | 选择拍号、设置每拍振动 |
| 下滑 | 选择配色 |
| 右滑 | 停止并退出应用；子页面右滑返回首页 |

点击 BPM 或拍号也可以进入对应页面，长按拍号查看手势指南。进入配置页面会停止播放，返回后需要手动开始。

6/8 的 BPM 以附点四分音符为单位，六个格子按 3＋3 分组。60 BPM 时一小节为两秒。击拍测速时，按两个大拍的节奏点击。

### 前台暗屏

首页底部三个按钮依次为：**振动 → 月亮（暗屏）→ 闪烁**。

1. 先开始播放，开启振动，并至少保留一个有振动的拍位。
2. 点击中间的月亮进入暗屏。暂时隐藏控制和闪烁，不改变原有振动节奏、BPM 或配色/闪烁偏好。
3. 点击暗屏恢复；左／上／下滑也只恢复界面，不会盲目进入设置。恢复时保持当前节拍相位，不补发振动。
4. 右滑或系统返回仍然停止并退出；离开首页或应用被隐藏/销毁也会停止。

进入/恢复时有短暂防误触，避免同一次点击穿透到新出现的按钮。错误提示会恢复可见控制。暗屏不保存为下次启动状态，不会自动开启振动或自动恢复播放。

**这是前台黑色页面，不是系统熄屏或后台运行。** 它仍请求保持屏幕开启，不预先承诺省电效果。已移除旧试验的五分钟上限，正常练习持续到手动停止或页面离开。测试步骤见 [前台暗屏说明](docs/foreground-dark.md)。

## 安装与限制

当前版本为 **0.6.0**（versionCode **23**），功能与已验收的 0.6.0-beta.3 相同，仅转为正式版本号。此前 0.5.11 的 [AstroBox PR #1156](https://github.com/AstralSightStudios/AstroBox-Repo/pull/1156) 已合并；0.6.0 的商店更新仍需通过 CreatorConsole 提交和审核，生成安装包不代表已经上架。

本仓库的 `source` 分支保存源码，[`main`](https://github.com/kyn0v/AstroBox-Xiaomi-Band-Metronome/tree/main) 分支由 CreatorConsole 管理安装包和商店图片。

- 目标设备为小米手环 9 Pro（336 × 480），其他机型尚未验证。
- **只支持前台运行**。后台试验和只读能力检测已从当前安装包移除；调研与历史记录见 [后台可行性调研](docs/background-research.md)。
- 长振动表示时间较长，不代表力度更强。高速或 6/8 下可能连震，已开始的振动无法立即截断。建议先低速测试。
- 自动化测试不能验证实际振动时序、触摸响应和耗电，仍需真机测试。
- 0.5.5 更换了包名，从此前版本迁移时会安装为新应用，需要重新填写设置。

## 开发

请在 `source` 分支开发，不要把源码合并到发布资源所在的 `main`。需要 Node.js 20+ 和 npm；重新生成图标时需要 Python 3。

```bash
npm ci --ignore-scripts
npm test
npm run build
```

输出文件：`dist/org.bandmetronome.app.debug.0.6.0.rpk`。

本地 `npm run build` 使用工具链公共调试签名。手动交付使用原项目签名工作流，不应拿公共调试签名替代现有正式签名。签名、测试和发布流程见 [开发说明（英文）](docs/development.md)。
