# 手环节拍器

小米手环 9 Pro 上的节拍器应用，使用 Vela JS 开发。

[英文说明](README.en.md)

## 功能

- 速度范围 50–250 BPM，支持百／十／个三列数字滚轮调速和击拍测速。
- 支持 2/4、3/4、4/4、6/8，每拍可设为长振动、短振动或无振动。
- 振动和闪烁可独立开关，拍点显示当前小节位置。
- 四种主题配色，设置保存在本地。
- 界面支持简体中文和英文，跟随系统语言。

## 操作

点击首页中央按钮开始或停止。

| 首页手势 | 功能 |
| --- | --- |
| 左滑 | 调整速度、击拍测速 |
| 上滑 | 选择拍号、设置每拍振动 |
| 下滑 | 选择配色 |
| 右滑 | 退出应用；子页面右滑返回首页 |

点击 BPM 或拍号也可以进入对应页面，长按拍号查看手势指南。进入配置页面会停止播放，返回后需要手动开始。

6/8 的 BPM 以附点四分音符为单位，六个格子按 3＋3 分组。60 BPM 时一小节为两秒。击拍测速时，按两个大拍的节奏点击。

## 安装与限制

当前源码为 **0.6.0-beta.1**，用于 [后台运行需求 #1](https://github.com/kyn0v/astrobox-xiaomi-band-metronome/issues/1) 的实机验证，尚未确认支持后台持续打拍。此前 0.5.11 的 [AstroBox PR #1156](https://github.com/AstralSightStudios/AstroBox-Repo/pull/1156) 已合并；这个测试包不代表商店版本已更新。

本仓库的 `source` 分支保存源码，[`main`](https://github.com/kyn0v/astrobox-xiaomi-band-metronome/tree/main) 分支由 CreatorConsole 管理安装包和商店图片。

- 目标设备为小米手环 9 Pro（336 × 480），其他机型尚未验证。
- 正常模式仍仅前台运行，离开首页后停止。独立后台试验不承诺系统保活，详见下文。
- 长振动表示时间较长，不代表力度更强。高速或 6/8 下可能连震，已开始的振动无法立即截断。建议先低速测试。
- 自动化测试不能验证实际振动时序、触摸响应和耗电，仍需真机测试。
- 0.5.5 更换了包名，从此前版本迁移时会安装为新应用，需要重新填写设置。

## 后台运行试验（测试版）

从首页下滑进入配色，点击「后台试验（测试版）」。先在正常页面设好 BPM、拍号与振动，建议首次用 4/4、120 BPM、短振动。

- 点击「开始 5 分钟」才启动，绝不自动恢复播放；正常首页的控制不变。
- 「尝试返回表盘」由系统处理返回，观察是否还在振动，不代表已获得后台权限。
- 页面记录应用隐藏事件、后台/总 JS 回调次数和最长间隔。**回调计数不是马达振动的证明。**
- 上限为 5 分钟；检测到较长的定时中断、系统时间回退或同步振动错误时停止，不追补漏拍。系统若挂起 JS，只能在恢复执行时检查期限。
- 「前台暗屏」只将页面变黑，仍请求保持亮屏，**不是熄屏或后台运行，也不保证省电**。点击黑屏可返回控制。
- 「停止并回首页」立即停止试验并恢复正常入口；重启应用不会恢复试验。
- 不用音频、定位或下载接口绕过后台限制，也不新增这类权限。

完整步骤与报告解释见 [后台试验说明](docs/background-probe.md)。没有实机验证前，不将此功能标为正式支持。

## 开发

请在 `source` 分支开发，不要把源码合并到发布资源所在的 `main`。需要 Node.js 20+ 和 npm；重新生成图标时需要 Python 3。

```bash
npm ci --ignore-scripts
npm test
npm run build
```

输出文件：`dist/org.bandmetronome.app.debug.0.6.0-beta.1.rpk`。

当前构建使用工具链公共调试签名，不是正式发行包。签名、测试和发布流程见 [开发说明（英文）](docs/development.md)。
