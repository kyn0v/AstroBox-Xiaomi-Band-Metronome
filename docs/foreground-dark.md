# 前台暗屏练习：0.6.0-beta.3

版本号：**0.6.0-beta.3 / versionCode 22**。这个版本只支持前台练习，不再提供后台试验或设备能力检测入口。之前的调研保留在文档和 Git 历史中。

## 按钮位置

首页下方三个图标，从左到右：

**振动 → 月亮（前台暗屏）→ 闪烁**

三个按钮的点击区域均为 64 × 48 设计像素，图标为 32 × 32。月亮会跟随当前配色；未播放或振动关闭时显示灰色图标。

## 正常用法

1. 建议先用 **4/4、120 BPM、短振动**检查效果。
2. 点击中央按钮开始播放，确保振动已打开，并至少有一个拍位设为长/短振动。
3. 点击中间的月亮。界面变黑，只保留低亮度的操作提示，振动继续。
4. 点击黑色页面恢复控制。恢复时不会额外振动、重新起拍或从第一拍重来；原先开启的闪烁在下一个拍位继续。
5. 暗屏中右滑或使用系统返回，会停止并退出。暗屏中的左／上／下滑只恢复界面，不直接进入设置。

未开始播放、振动关闭、全部拍位为“无”，或已知保持亮屏失败时，不会进入暗屏，首页会给出提示。应用不会替用户自动开启振动或更改拍位。

## 这不是什么

- **不是后台运行**：离开首页、切出应用或页面被隐藏/销毁，仍会停止。
- **不是真正熄屏**：只绘制黑色页面，仍使用系统保持亮屏请求。
- **不改变系统亮度**：不会写入硬件亮度或自动亮度设置。
- **不保证省电**：不闪烁、不刷新拍点可能减少一部分显示工作，但 CPU 和马达仍运行，实际耗电需要测量。
- **没有五分钟上限**：旧上限属于后台诊断；正常前台练习会持续到手动停止或页面离开。
- **不会自动恢复**：暗屏状态和播放状态不保存，重开应用仍处于停止状态。

## 防误触与异常

进入暗屏和点击恢复时各有约 350 ms 的点击抑制，避免同一次点击穿透到新出现的按钮。刚进入后立即点一下，可能会被这个短暂保护忽略，稍等再点即可。右滑或系统返回仍可正常停止退出。

暗屏中若出现可检测到的振动、保存或保持亮屏错误，会恢复可见控制并显示错误。已经开始的一次硬件振动仍可能自然结束，应用没有可用的强制截断接口。

## 本轮实机测试建议

1. **位置和点击**：确认月亮位于振动、闪烁中间；三个图标互不误触，四种配色均正常。
2. **连续性**：120 BPM 播放后进入暗屏，观察 30 秒，再恢复；是否漏拍、重复起拍或出现一次额外振动？
3. **暗屏视觉**：看是否完全没有节拍闪烁，只保留低亮度提示。检查恢复后的 BPM、拍号和主题没有改变。
4. **防误触**：在原中央播放按钮的位置点击恢复，确认这一下只唤醒 UI，没有同时停止或开始播放。
5. **退出**：暗屏中右滑退出，确认不再产生新振动；重开后不会自动播放或自动暗屏。
6. **设置保留**：分别在闪烁开启/关闭时进入并恢复，确认没有改掉原偏好。振动关闭或全部静音时，月亮应提示而不是自动更改设置。
7. **不同节拍**：用 3/4 和 6/8 测一次，尤其注意恢复后拍位没有重置。先低速，不要用高速长振动判断精度。
8. **长时间前台**：在舒适条件下测试超过五分钟，确认不会再按旧试验上限停止。记录明显耗电、发热或系统主动退出；不适时立即停止。
9. **普通功能回归**：停止、调速、击拍测速、节拍设置、配色和普通退出仍正常。

反馈时提供应用版本、设备/固件、BPM/拍号，以及具体是哪一步出现问题。只需手动安装测试，不需要刷固件、系统权限修改或其他辅助应用。
